## Ворота текущего atom

Нужны восемь основных семейств источников. У каждого есть публичный baseline, прямой путь там, где утверждение требует авторитета, и один запасной путь. Необязательные ускорители не являются единственным маршрутом и не обязательны для метода.

Проверка детерминированная: связи и запасные пути целы, отзыв не доказывает официальное правило, кэш не доказывает живое наличие, канал с правом записи не бронирует сам, цены поездки не лежат в реестре как способность источника.

Живые пробы ограничены и только для чтения. Свой агрегатор, сборщик страниц и сервис поставщиков не строятся.

## PASS / REPAIR / STOP

Только для текущего atom про источники.

**PASS:** семейства покрыты, baseline не зависит от ускорителя, тесты зелёные, живые пробы честно отделяют прочитанное от неизвестного, открытых блокеров контракта нет.

**REPAIR:** нарушен обязательный маршрут или реестр смешивает способность источника с ценой поездки. Чинится этот стык, без новой инфраструктуры.

**STOP:** осмысленный маршрут требует собственного агрегатора, фермы сборщиков или платёжного доступа, чтобы источник вообще включить. Либо после одного запасного пути утверждение остаётся недоказуемым: тогда это UNKNOWN, а не повод расширять архитектуру.

Исполнитель сам atom не принимает.

## После PASS

`OWNER_REAL_TRIP_PILOT_V1`.

Одна настоящая поездка владельца: запрос, подбор не больше пяти, первая проверка, явный выбор, план, вторая проверка, итоговый документ и снимок. Публичный веб, репозиторий и необязательные приложения используются только там, где дают существенную пользу. Полную постановку этого шага сейчас не пишем.

## Позже, только по наблюдению

Локальная автоматизация — если реальная поездка покажет повторяющуюся механическую боль в расчётах, сохранении, оформлении или запуске. Заранее она не назначается.

Следующий шаг после реальной поездки определяется найденной болью или пользой. Другие типы поездок можно калибровать позже.
