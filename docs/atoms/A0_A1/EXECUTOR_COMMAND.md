2. НЕИЗМЕНЯЕМЫЕ ПРОДУКТОВЫЕ ПРАВИЛА
Primary product path: самостоятельный ENOT_CHAT_START.md + явный brief
в обычном облачном чате. Dev-инструменты не протекают в traveler UX.

Поток: INTAKE → DISCOVER → Critic 1 → до 5 → пауза → явный выбор
актуального варианта → recheck выбранного → PLAN → Critic 2 → publish.
До выбора нет подробного guide для кандидатов. «Продолжай» не выбирает
лидера. Неоднозначный/старый ID требует только уточнения выбора.

Пять — cumulative число уникальных опубликованных концепций одного цикла,
включая условные и выдачу частями. 3+2 можно, 5+бонус нельзя; удаление
карточки не освобождает использованный слот. Stable ID не переиспользовать.
Новый цикл после заполнения пяти — только по явному пользовательскому
refine/разрешению, с видимой причиной. Не заполняй квоту плохими вариантами.

Brief версионируется; все veto и прежние неизменённые пожелания сохраняются.
Не выводи город, гражданство, бюджет/оплату из IP, языка и памяти владельца.
Не запрашивай секреты, паспортные/платёжные реквизиты и лишние личные данные.

Evidence: claim/value/unit, тип/полномочия источника, реальный URL или
user-reported свидетельство, доступная точность даты получения, даты/состав/
тариф применимости, ограничения, freshness/recheck. Snippet не прочитанные
условия; блог не официальный орган; cache не live quote; offer не booking.
Цена одного места × группа и сумма малых запросов не подтверждают квоту.
Hard checks: PASS/FAIL/UNKNOWN/NOT_APPLICABLE с основанием. Hard FAIL
исключает рекомендацию; критичный UNKNOWN делает вариант условным.
Не повышай статус из-за отсутствия возражений или силы модели.

Свежесть зависит от смысла и решения, не одного TTL: recheck существенного
перед PLAN; перед покупкой — явная перепроверка у поставщика; часы/события
для даты визита; правила из применимых официальных источников.
Старым данным не присваивать новую дату. Нет доступа — одна разумная
разрешённая альтернатива, затем конкретный unknown; никакого обхода auth.

All-in: дверь-дверь, багаж, жильё/сборы, трансферы, еда, активности,
применимые связь/страховка/комиссии и резерв. Возвратный депозит отдельно
как ликвидность. Включённые услуги не считать дважды. Строки имеют
количество/единицу/цену или диапазон/валюту/основание/включённость.
Валюты конвертировать по указанным курсу/дате/комиссиям, не складывать.
Unknown обязательный расход не ноль. Нижняя граница выше потолка — FAIL;
пересечение потолка или критичный unknown — условно, не PASS.
Процент экономии только для сопоставимой полной корзины и baseline > 0.

Сохрани существующие presets, rubric и рейтинг Σ(weight×score/5).

веса. Нулевой вес не отменяет hard check. Близкие итоги не точный победитель.
Без вычислителя не заявляй вычисленную sensitivity; «еноты» отдельно от
рейтинга и скрыты при критичных unknown.

Critic 1 проверяет сильнейшую простую альтернативу, разнообразие,
