# Текущее состояние проекта

Дата: **2026-09-30**. Проект **0.3.0**. Протокол чата **0.2.3**.

Основной потребитель — **владелец**. Сильный облачный чат остаётся runtime. Переносимость для друга сохранена как будущая возможность и не является release gate.

Атом `ENOT_A0_A1_CLOUD_FIRST_VERTICAL_PROOF_V1` закрыт как `STOP_OWNER_SCOPE_CHANGE`. Это не PASS и не technical FAIL. История — в [docs/atoms/A0_A1/ACCEPTANCE.md](docs/atoms/A0_A1/ACCEPTANCE.md).

Активный atom: `ENOT_OWNER_FIRST_SOURCE_INTELLIGENCE_V1`. Исполнитель сам его не принимает. Если владелец поставит PASS, следующий рекомендуемый atom — `OWNER_REAL_TRIP_PILOT_V1`. A2 не назначен.

| Область | Состояние |
|---|---|
| Визуальное направление | Пользователь одобрил; стиль сохранён |
| Основной потребитель | Владелец продукта |
| Runtime | Сильный облачный чат; веб, репозиторий и доступные инструменты — необязательные ускорители |
| Друг / родственник | Метод не удалён; не текущий release gate |
| Этапность | До пяти вариантов → явный выбор → план |
| Реестр источников | Routing prior в config/sources.yaml, не whitelist и не база цен |
| Приложение / сервер | Не реализуются в этом atom |
| A2 | Условный, не начат |

## Активная работа

Маршрут утверждения: нужный claim → семейство источника → доступный baseline или прямой официальный путь → одно чтение → существующий Evidence. При блокировке один fallback, затем UNKNOWN. Цены поездки в реестр не записываются.

Не начинать туристическую БД, scraper, собственный агрегатор, оплату, бронирование и установку новых интеграций.
